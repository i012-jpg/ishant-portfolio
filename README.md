# 🌐 Ishant Portfolio Website

A modern, responsive personal portfolio built with **HTML, CSS, and vanilla JavaScript**. It showcases Ishant's skills, projects, services, and experience with a dark visual theme, smooth animations, and responsive layouts.

## 🚀 Features

- Fully responsive design
- Modern dark theme with glassmorphism
- Animated hero section and typing effect
- Smooth-scroll navigation and sticky navbar
- Skills progress bars
- Featured projects showcase
- Services and experience timeline
- Testimonial section
- Validated contact form
- Social links and back-to-top button
- SEO-friendly page metadata

## 🛠️ Technologies Used

- HTML5
- CSS3, responsive design, and CSS animations
- Vanilla JavaScript
- Inline SVG illustrations and icons
- No frameworks or build tools

## 📂 Sections

- Home
- About
- Skills
- Projects
- Services
- Experience
- Testimonials
- Contact

## ▶️ Run Locally

Open `index.html` in a browser, or serve this folder with a static web server. No package installation or build step is required.
