# Security and privacy

## Data handling

This is a static website. It has no application server, account system, analytics, or database.

The contact form validates fields in the browser and opens a pre-filled Gmail draft. Form contents are included in the Gmail compose URL and are handed to Google to create the draft. The site itself does not transmit or store the message. Review the draft before sending it, and do not enter passwords, payment details, or other sensitive information.

External project and social links open in a new tab with `noopener noreferrer`.

## Reporting an issue

For a security or privacy concern about this portfolio, email [parjapatuishant@gmail.com](mailto:parjapatuishant@gmail.com) with a brief description and steps to reproduce. Do not include passwords or other people's private information.
